### 🌤️ WeatherVibe — Live Weather Experience

A weather app that turns live weather data into an immersive animated sky.

**Highlights**
- City search and current-location weather
- Animated rain, lightning, snow, clouds, sun, moon, and stars
- Detailed weather, air-quality, forecast, and sun/moon information
- Browser-generated ambient weather audio
- Automatic refresh and Celsius/Fahrenheit toggle

**Built with:** HTML5 · CSS3 · Vanilla JavaScript · Canvas API · SVG · Web Audio API
