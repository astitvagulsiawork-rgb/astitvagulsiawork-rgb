### 🛒 Amazon Clone — Frontend E-commerce Demo

A multi-page e-commerce experience inspired by Amazon's interface.

**Highlights**
- 17 connected pages and a 36-item product catalog
- Working cart, checkout, order confirmation, and order history flows
- Search, category filters, sorting, deals, and related products
- Browser-based cart and order persistence with `localStorage`
- Responsive layout built without frameworks or a backend

**Built with:** HTML5 · CSS3 · Vanilla JavaScript

[**View Project →**](https://github.com/astitvagulsiawork-rgb/Amazon-Clone-Project)

### 💰 A Modern Ledger — Expense Tracker

A browser-based expense tracker designed with a distinctive ledger-book aesthetic.

**Highlights**
- Monthly spending dashboard and category breakdown
- Budget limits, recurring expenses, and transaction management
- Multi-currency support with exchange-rate conversion
- CSV import/export and ledger-style PDF generation
- Local-first data storage with backup reminders

**Built with:** HTML5 · CSS3 · Vanilla JavaScript · SVG · jsPDF

[**View Project →**](https://github.com/astitvagulsiawork-rgb/Expanse-Tracker)

### 🌤️ WeatherVibe — Live Weather Experience

A weather app that turns live weather data into an immersive animated sky.

**Highlights**

- Animated rain, lightning, snow, clouds, sun, moon, and stars
- Detailed weather, air-quality, forecast, and sun/moon information
- Browser-generated ambient weather audio
- Automatic refresh and Celsius/Fahrenheit toggle

**Built with:** HTML5 · CSS3 · Vanilla JavaScript · Canvas API · SVG · Web Audio API
